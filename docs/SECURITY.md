# Security policy

Report suspected vulnerabilities privately to [david.lynch.home@gmail.com](mailto:david.lynch.home@gmail.com).
Do not include vulnerability details in public issues or pull requests.

Include the affected version or commit, component, steps to reproduce, potential impact, and any
suggested fix. Omit credentials and personal data from examples. The maintainer will coordinate
investigation and disclosure through that email thread; no response deadline is promised.

Reports against the current template are welcome. Derived projects own their deployed versions,
patching, and support policy. Before adopting this template, replace this address with your own
monitored private reporting channel and document supported versions and response expectations.
